Системные требования

  • Windows 10 (1607+) или Windows 11
  • Только 64-бит
  • WebView2 Runtime (в Windows 11 уже есть)
  • ОЗУ: от 4 ГБ, для сборок с модами — 8 ГБ
  • Диск: от 2 ГБ, сборкам нужно больше
  • Видеокарта с OpenGL 3.2+ (для 1.17+)
  • Интернет для первой установки
  • Linux и macOS — в планах

Windows может показать «Система Windows защитила ваш компьютер». Лаунчер пока не подписан цифровой подписью, поэтому SmartScreen его не узнаёт. Нажмите «Подробнее» → «Выполнить в любом случае».

Распакуйте архив целиком в отдельную папку (например, C:\Games\Blockify) и запустите BlockifyLauncher.exe. Прямо из архива лаунчер не запустится.

Скачивайте только с GitHub или с этого сайта. Сверить файл можно по SHA256 из SHA256SUMS.txt на странице релиза: Get-FileHash .\Blockify-portable-win-x64.zip в PowerShell.

Вопросы

Это бесплатно?

Да. Лаунчер бесплатный, код открыт на GitHub под лицензией MIT. Сама игра Minecraft: Java Edition продаётся отдельно на minecraft.net.

Нужен ли вход в аккаунт?

Регистрации в самом лаунчере нет. Для официальных серверов, скинов и Realms войдите через аккаунт Microsoft, на котором куплена Minecraft: Java Edition. Для игры без интернета и по локальной сети можно создать локальный профиль. Играть в Minecraft можно только купив игру — этого требует лицензионное соглашение (EULA) Mojang.

Как устроен вход через Microsoft?

Страница входа Microsoft открывается во встроенном окне лаунчера. Лаунчер не сохраняет пароль: после входа на вашем компьютере хранится только токен входа. Скачивайте Blockify только с GitHub или с этого сайта.

Windows пишет «Система Windows защитила ваш компьютер». Что делать?

Лаунчер пока не подписан цифровой подписью, поэтому SmartScreen его не узнаёт. Нажмите «Подробнее» → «Выполнить в любом случае». Подлинность архива можно проверить по SHA256 из файла SHA256SUMS.txt на странице релиза.

Пишет, что нужен WebView2

Интерфейс лаунчера работает на Microsoft Edge WebView2. В Windows 11 он уже установлен, в Windows 10 обычно приходит с обновлениями. Если его нет — скачайте «Evergreen Bootstrapper» на сайте Microsoft.

А Linux и macOS?

Сейчас только Windows 10 и 11 (64-бит). Linux и macOS — в дорожной карте.
